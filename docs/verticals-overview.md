# Verticals Overview

Embric's architecture is adaptable to multiple Web3 verticals, enabling protocols and projects to integrate utility mining in ways that suit their domain.

---

## 1. DePIN Networks

Embric provides an efficient framework for decentralized physical infrastructure networks (DePIN) to:

* Reward uptime and presence proofs
* Validate data from edge devices
* Incentivize location-based or hardware interactions

BRIC becomes the native coordination token across nodes.

---

## 2. DAOs and Governance Systems

Governance often suffers from participation fatigue. Embric reactivates DAOs by:

* Mining proposal creation, voting, and evaluation
* Linking BRIC to verified contribution rather than just holdings
* Enabling action-based on-chain governance incentives

---

## 3. Web3 Compute & ZK Proof Systems

Computation is valuable — especially in decentralized contexts. Embric supports:

* Rewarding provable off-chain computation
* Tying BRIC to zero-knowledge proof generation
* Incentivizing trustless compute participation

---

## 4. Data Verification & Indexing Protocols

Clean, validated data is foundational. Embric lets data-centric protocols:

* Reward data validators and curators
* Mine token value via indexing or accuracy scoring
* Enforce source verification before reward distribution

---

## 5. Application-Level dApps

Any dApp can plug into Embric to:

* Add utility-based BRIC incentives
* Create micro-reward systems
* Encourage user actions with built-in value return

---

**From governance to hardware — if it creates value, Embric can mine it.**
